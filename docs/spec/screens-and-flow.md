# 画面とフロー

## 1. 問題管理機能

最低限必要な機能は以下とする。

- 問題の新規作成
- 問題の編集
- 問題の複製
- 問題のアーカイブ
- 問題の削除
- 問題一覧表示
- 問題詳細表示
- 検索
- 絞り込み
- 並び替え

検索・絞り込み条件:

- タイトル
- 問題文全文
- タグ
- 科目
- 分野
- 難易度
- 状態
- 作成日
- 更新日
- 画像有無
- 解説有無
- AI評価有無

並び替え:

- 更新日順
- 作成日順
- 難易度順
- タイトル順

## 2. 画面仕様

### 2.1 ダッシュボード

- 総問題数
- 科目別件数
- 未評価問題数
- 解説未作成問題数
- 最近更新した問題

### 2.2 問題一覧

- 一覧表示
- 検索、絞り込み、ソート
- 画像有無、解説有無、AI評価済みの可視化

### 2.3 問題詳細

- 問題文レンダリング
- 解答レンダリング
- 解説レンダリング
- 使用画像一覧
- AI評価履歴
- 解説版履歴

### 2.4 問題作成・編集

- `Markdown + TeX` エディタ
- 数式プレビュー
- 画像アップロード
- 本文への画像挿入
- 自動保存

## 3. 問題作成フロー

基本的な作業フローは以下とする。

1. 新規問題を作成する
2. 問題文を `Markdown + TeX` で入力する
3. 必要な画像をアップロードして本文に挿入する
4. 解答メモや方針を入力する
5. AIに難易度評価を依頼する
6. AIに解説生成を依頼する
7. 必要に応じて手修正する
8. 状態を「完成」にする

## 4. 出力仕様

Overleaf 前提ではなく、アプリ内閲覧と汎用出力を優先する。

優先順位の高い出力:

- アプリ内レンダリング表示
- Markdown エクスポート
- PDF 出力
- JSON バックアップ

後回しでよいもの:

- LaTeX エクスポート
- 外部執筆ツールとの直接連携
