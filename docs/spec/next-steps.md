# Next Steps

現状の UI を確認した時点で、次の実装候補が残っている。

## 1. 画像管理 UI

現状は `Markdown + TeX` の本文入力はあるが、問題に紐づく画像を管理する UI がない。

必要なもの:

- 画像アップロード
- 問題ごとの画像一覧
- 画像プレビュー
- 画像差し替え
- 画像削除
- 本文への画像挿入補助

実装方針候補:

- 問題詳細画面に「画像」タブを追加する
- または `/problems/[problemId]/assets` を追加する

## 2. AI 操作 UI

現状は AI による難易度評価と解説生成の実行導線がない。

必要なもの:

- `難易度をAI評価` ボタン
- `解説をAI生成` ボタン
- AI実行中状態の表示
- AI評価結果の表示
- AI生成結果の保存導線

実装方針候補:

- 問題詳細画面のヘッダまたは専用タブに配置する

## 3. 解説版管理 UI

現状は解説の版管理 UI がない。

必要なもの:

- 解説版一覧
- 各版の生成元表示
  - manual / ai
- 採用中の版の表示
- 版の比較
- 採用切替

実装方針候補:

- 問題詳細画面に「解説版」タブを追加する
- または `/problems/[problemId]/versions` を追加する

## 4. 設定画面

現状は `/settings` がない。

将来的に置く候補:

- AIモデル設定
- 出力設定
- アプリ共通設定

## 5. エクスポート UI

現状は Markdown / PDF / JSON の出力画面や導線がない。

必要なもの:

- 問題単位の出力
- 一覧からの出力
- Markdown エクスポート
- PDF 出力
- JSON バックアップ

実装方針候補:

- `/exports` を追加する
- または問題詳細画面に出力セクションを追加する

## 6. 問題一覧の管理指標強化

現状の一覧 UI には管理上ほしい指標がまだ足りない。

追加候補:

- 画像あり / なし
- 解説あり / なし
- AI評価済み / 未評価

追加候補の絞り込み条件:

- 画像有無
- 解説有無
- AI評価有無

## 7. 優先順位メモ

優先度は次の順を想定する。

1. 画像管理 UI
2. AI 操作 UI
3. 解説版管理 UI
4. 設定画面
5. エクスポート UI
6. 問題一覧の管理指標強化

## 8. 画面追加を最小限にする場合の方針

画面数を増やしすぎたくない場合は、まず次の構成で進める。

- 問題詳細に「AI」タブを追加
- 問題詳細に「画像」タブを追加
- 問題詳細に「解説版」タブを追加
- `/settings` だけ独立ページとして追加
