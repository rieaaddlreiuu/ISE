# 全体方針

## 1. 目的

個人用の作問管理システムとして、以下の課題を解消することを目的とする。

- 作成した問題の管理が煩雑になりやすい
- 解説の文字起こし、清書、整形に手間がかかる
- 問題の難易度評価が主観的になりやすい

本システムは、問題文・解答・解説・画像・難易度評価・AI生成結果をまとめて扱えるようにする。

## 2. 基本方針

- 利用者は本人のみを想定する
- このシステム自体を問題データの正本とする
- Overleaf は基本的に使用しない
- 本文はすべて `Markdown + TeX` 形式で管理する
- 画像を問題に紐づけて管理する
- AIの出力は完成版ではなく下書きとして扱う

## 3. 管理対象

管理の最小単位は「問題」とする。1問ごとに少なくとも以下を保持する。

- 問題ID
- 管理番号
- タイトル
- 科目
- 分野
- タグ
- 問題文
- 解答
- 解説
- 作問メモ
- 難易度情報
- AI評価結果
- 画像
- 状態
- 作成日時
- 更新日時

## 4. スコープ

初期段階で対象に含めるもの:

- 問題の作成、編集、検索、閲覧
- `Markdown + TeX` での本文管理
- 画像アップロードと本文埋め込み
- AIによる難易度評価
- AIによる解説生成
- 解説の版管理
- PDF または印刷向け出力

初期段階で対象外または後回しとするもの:

- Overleaf 連携
- 複数ユーザー対応
- 高度な権限管理
- 画像を用いたAI読解の必須対応
