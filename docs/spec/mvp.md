# MVPと確定事項

## 1. MVP

初期実装の範囲は以下とする。

- 問題CRUD
- `Markdown + TeX` エディタ
- 数式プレビュー
- 画像アップロードと本文挿入
- 問題一覧、検索、絞り込み
- AI難易度評価
- AI解説生成
- 解説版管理
- アプリ内表示
- PDF または印刷向け出力

## 2. 非機能要件

個人用として特に重視する点は以下とする。

- 入力が失われにくいこと
- 検索しやすいこと
- AI生成が極端に遅くないこと
- データを後から持ち出しやすいこと

そのための要件:

- 自動保存
- 更新日時の管理
- JSON エクスポート
- Markdown エクスポート
- PDF 出力

## 3. 権限仕様

初期仕様ではシングルユーザー前提とする。

- 複数ユーザー管理は行わない
- 高度な権限制御は導入しない
- 将来的に `createdBy` などを追加できる余地は残す

## 4. 確定事項

現時点での確定事項は以下の通り。

1. このシステムを問題データの正本とする
2. Overleaf は基本的に使わない
3. 本文形式は `Markdown + TeX` とする
4. 問題文・解答・解説・メモは同形式で保存する
5. 画像は問題に紐づく添付資産として管理する
6. 画像は本文中に Markdown 記法で埋め込めるようにする
7. AI難易度評価とAI解説生成を行う
8. AI出力は履歴付きの下書きとして保存する
9. 解説は版管理する
10. 初期段階ではシングルユーザー前提とする
